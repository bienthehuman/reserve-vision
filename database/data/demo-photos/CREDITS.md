# Demo photo credits

The demo listings' photos (slice 7.1) are real photographs from Wikimedia Commons, each marked **CC0** or **public domain** on its own source page. Nothing here is Unsplash, Pexels or Pixabay (their licences are not CC0), and there are no identifiable people, faces, logos or brand names.

Each file is the Commons file resized to at most 1920 px on the long side and re-saved as a JPEG at quality 82, with all metadata removed. The seeder then runs it through `PhotoProcessor` like any upload. [`photos.php`](photos.php) has the same rows for the seeder (and the default `alt` text); a test checks that this table, that file and the images agree, and that every licence is `CC0-1.0` or `Public Domain`.

CC0 and public-domain works need no credit; the authors are named anyway. The "Checked" date is when the licence was read on the source page itself.

## Adding or replacing a photo

1. Find it on Commons and open its file page. Accept it only if that page says CC0 (or public domain) and the licence applies to the photo itself (a CC0 tag on a photo of someone else's artwork is not enough). Skip anything with a person, a face, a logo or a brand name, and anything you cannot verify.
2. Save it here as a JPEG (long side at most 1920 px, quality about 82, metadata stripped; keep the folder under 12 MB), named for what it shows.
3. Add the row to `photos.php` (`file`, `kind`, `alt`, `source`, `author`, `licence`) and to the table below. `kind` is one of `exterior`, `bunk`, `bedroom`, `apartment`, `kitchen`, `bathroom`, `laundry`.
4. Run `composer test -- --filter=DemoPhotos`. The seeder's hash test (`DemoSeederTest`) changes too, on purpose: copy the printed hash and say why in the PR.
